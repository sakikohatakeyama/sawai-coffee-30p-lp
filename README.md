# 澤井珈琲ドリップコーヒー オールスターズ30｜商品ページ用

予約商品「オールスターズ30」（ドリップバッグ30袋入り）の商品ページ用デザインです。**JPG画像にして商品ページに載せる前提**のため、動き・リンクは入れていません。スマホ基準の1カラム（幅最大560px）で、文字は大きめ。特集ページ（sawai-coffee-30p-fukubukuro）とテイスト・素材をそろえています。

予約キャンペーン終了後も販売するため、**キャンペーンの内容・価格はFV下の「キャンペーン詳細」1ブロックだけ**に入れています。終了後はそのブロック（`<!-- ===== キャンペーン詳細（1枚）` のコメントの section）を削除すれば、そのまま通常販売用になります。

- `index.html` … ページ本体（HTML・CSS・JSを1ファイル）
- `img/title.png` … FVのタイトル（ダウンロードの「澤井珈琲オールスターズ30 手描きロゴ.png」（特集ページのFVと同じロゴ）を白＋「30」黄色 #ffe644 に色替え）
- `img/` のそのほか：logo.png／photo.jpg（写真）／pk-*.webp（ドリップバッグ30種の切り抜き）

## 構成
1. ヘッダー（ロゴ）
2. FV：「30種類を飲み比べ」＋タイトル＋「ドリップバッグ30袋入り」＋ドリップバッグを斜め（-14°）に4段並べ、画面の外まではみ出させてインパクトを出す（キャンペーン終了後もそのまま使える内容）
3. **キャンペーン詳細（1枚）**：発売日11月15日／お得なご予約キャンペーン開催中！／予約販売限定価格2,250円（税込）／送料無料・ポイント2倍／予約受付期間・発売日
4. リード「30袋、ぜんぶ違う珈琲。」
5. 3つのポイント
6. 写真
7. 入っている30種類（4つの味わいタイプごと。データは下部の `const coffees`）
8. 30袋の楽しみ方（3つ）
9. 商品詳細（商品名・内容量のみ）
10. 締め：「今日の一杯は、どれにしよう。」＋「30種類の澤井珈琲で、毎日にちいさな楽しみを。」＋タイトルロゴ＋斜めに並ぶドリップバッグ2段（赤背景）
11. フッター（ロゴ）

## 確認が必要な点
- 商品詳細は商品名・内容量だけです。賞味期限・原材料・保存方法などを載せる場合は内容をご支給ください
