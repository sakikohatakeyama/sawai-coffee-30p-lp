# 澤井珈琲ドリップコーヒー オールスターズ30｜商品ページLP

予約商品「オールスターズ30」（ドリップバッグ30袋入り）を購入する商品ページ用のLPです。スマホで見やすい1カラム（幅最大560px。PCでは中央に表示）で、特集ページ（sawai-coffee-30p-fukubukuro）とテイスト・素材をそろえ、余白と細い線で少しキレイめにしています。

- `index.html` … ページ本体（HTML・CSS・JSを1ファイル）
- `img/` … 画像（特集ページと同じもの）：logo.png／fv-sp.jpg（FV）／fv-sp-cup.webp（FVのカップ）／photo.jpg（写真）／pk-*.webp（ドリップバッグ30種の切り抜き）
- フォント：日本語はヒラギノ角ゴ（ない環境はNoto Sans JP）、数字・英字はJost。`font-feature-settings:"palt"`

## 構成
1. ヘッダー（ロゴ・澤井珈琲トップへリンク）
2. FV：特集ページのスマホFVと同じ（画像＋袋が流れる2列＋カップ）
3. リード「30袋、ぜんぶ違う珈琲。」
4. 価格カード：予約販売限定価格2,250円（税込）・送料無料・ポイント2倍・1袋あたり75円／内容・予約受付期間・発売日
5. 3つのポイント（30種すべて違う銘柄／4つの味わいで飲み比べ／1杯ずつのドリップバッグ）
6. 写真
7. ラインナップ：4つの味わいタイプごとに30種（写真＋番号＋銘柄名）。データは下部の `const coffees`（特集ページと同じ並び・タイプ分け）
8. 30袋の楽しみ方（3つ）
9. スケジュール：10/24（土）00:00 予約受付開始 → 11/15（日）10:00 予約受付終了 → 11/15（日）発売日
10. 商品詳細＋注意書き
11. 特集ページへのボタン（`▼ 特集ページのURL` のコメント下。今はGitHub PagesのURLなので、楽天GOLDの公開URLに差し替え）
12. フッター

動きはスクロールでのふわっと表示と、FVの袋の流れだけ。`prefers-reduced-motion` の方には止めて表示します。

## 確認・差し替えが必要な点
- 特集ページのURL（上記11）
- 楽天の商品ページの「商品説明文（スマートフォン用）」はCSS・JSが使えないため、このLPは楽天GOLDにアップして、商品ページから画像バナーやリンクでつなぐ想定です
- 注意書きは特集ページと同じ1文のみ。賞味期限・原材料・保存方法などを載せる場合は内容をご支給ください
